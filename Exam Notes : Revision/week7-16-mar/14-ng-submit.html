How ng-submit differs from ng-click on button

  • ng-submit is placed on the <form> element and handles all ways the form can be submitted (Enter key, submit button click).
  • It also automatically prevents the default browser form submission (no page reload).
  • ng-click on a button only fires on mouse click — Enter key won't trigger it.
