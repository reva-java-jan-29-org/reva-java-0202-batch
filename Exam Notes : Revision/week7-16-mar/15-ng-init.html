⚠️ When to use ng-init

  • Use it for simple, template-level initialization (e.g., loop aliases, quick defaults).
  • For non-trivial initialization, prefer setting values inside a controller function — this keeps business logic out of the template.
  • Common use: ng-init="alias = item" inside ng-repeat to create a local alias for a complex nested object.

Controller-based equivalent:

$scope.count = 0; $scope.label = 'Clicks';
