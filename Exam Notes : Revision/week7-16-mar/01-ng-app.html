ng-app — Bootstrap the AngularJS App

Purpose: Marks the root element of an AngularJS application. Everything inside this element is managed by AngularJS.

This entire page is bootstrapped with ng-app="myApp" on the <html> tag.

AngularJS expression: {{ 2 + 3 }} (should show 5)

String expression: {{ "Hello, " + "AngularJS!" }}

Without ng-app, AngularJS expressions like {{ }} would not be evaluated and would appear as raw text in the browser.
