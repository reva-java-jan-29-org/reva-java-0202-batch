⚠️ Why use ng-src instead of src="{{ }}"?

With plain src="{{ imgUrl }}", the browser immediately fires a request for the literal string "{{ imgUrl }}" before Angular processes the template — causing a 404. ng-src waits for Angular to resolve the expression first.
